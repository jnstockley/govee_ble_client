# Library Logging Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Provide useful, private diagnostics controlled by the embedding app.

**Architecture:** Module loggers propagate through the package logger with a
NullHandler. A private context helper supplies connection correlation and timed
debug spans without exposing caller data.

**Tech Stack:** Python logging, asyncio, pytest, Ruff.

**Spec:** `docs/superpowers/specs/2026-10-24-logging-design.md`

## Global Constraints

Preserve cancellation, deadlines, cleanup, and no-replay behavior. No new runtime
dependencies. No raw sensitive data or exception messages in records.

## Review Focus

Host handlers/levels must survive import; concurrent connections need distinct
tokens; cancellation must propagate; suppressed cleanup failures need error
types; debug records must exclude payloads and identifiers.
